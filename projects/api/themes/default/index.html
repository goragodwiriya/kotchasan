REST API ด้วย ApiController

API หนังสือที่อ่านได้ทุกคน และเพิ่ม แก้ไข ลบได้เมื่อส่ง Bearer token ทุกคำตอบเป็น JSON รูปแบบเดียวกัน กดปุ่ม ลองเรียก แล้วกด ส่งคำขอ ได้ทันที

Endpoint

MethodURLทำอะไรToken
GETapi.php/v1/books รายการหนังสือ ค้นหาด้วย ?q= แบ่งหน้าด้วย ?page=-
GETapi.php/v1/books/1 หนังสือหนึ่งเล่ม-
POSTapi.php/v1/books เพิ่มหนังสือ ส่ง title, author, priceต้องใช้
PUTapi.php/v1/books/1 แก้ไขหนังสือ ส่งข้อมูลครบทุกช่องต้องใช้
DELETEapi.php/v1/books/1 ลบหนังสือต้องใช้

คำขอ

มาจาก api_tokens ใน settings/config.php ลองเอาเครื่องหมายออกแล้วส่ง POST เพื่อดูคำตอบ 401
