จัดการสินค้า (CRUD)

เพิ่ม แก้ไข ลบ ค้นหา เรียงลำดับ และแบ่งหน้า บน SQLite ที่สร้างให้เองในการเปิดครั้งแรก ใช้ MySQL ได้โดยแก้ settings/database.php ไฟล์เดียว

{ALERT} {CONTENT}

ไฟล์ในตัวอย่างนี้

  • index.phpไฟล์ทางเข้า กำหนด DATA_FOLDER แล้วโหลด Kotchasan
  • settings/database.phpการเชื่อมต่อฐานข้อมูล (SQLite หรือ MySQL) และ prefix ของตาราง
  • modules/index/controllers/index.phpController อ่านคำขอ ตรวจฟอร์ม แล้วเรียก Model
  • modules/index/models/product.phpModel สร้างตาราง ค้นหา เพิ่ม แก้ไข และลบ ด้วย Query Builder และ DB
  • modules/index/views/index.phpView แปลงข้อมูลเป็น HTML จาก template
  • themes/default/*.htmlเลย์เอาต์ ตาราง แถว และฟอร์ม
  • datas/ไฟล์ database.sqlite (ต้องเขียนได้ และไม่เปิดให้ดาวน์โหลด)
