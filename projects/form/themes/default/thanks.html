เกิดอะไรขึ้น

  1. ฟอร์มส่งข้อมูลแบบ POST มาที่ index.php พร้อม CSRF token
  2. Controller ตรวจ token และข้อมูลทุกช่อง ผ่านแล้วเก็บข้อมูลไว้ใน $_SESSION
  3. ตอบกลับด้วย redirect 303 ให้เบราว์เซอร์เปิด index.php ใหม่แบบ GET
  4. หน้านี้แสดงข้อมูลจาก session หนึ่งครั้งแล้วลบทิ้ง กดรีเฟรชจึงกลับไปเป็นฟอร์มเปล่า
