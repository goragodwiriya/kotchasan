Ajax ด้วย fetch()

JavaScript เรียกเมธอดของ Controller ผ่าน URL แล้วรับคำตอบเป็น JSON ไม่ต้องโหลดหน้าใหม่ และไม่ใช้ไลบรารีภายนอก ทุกกล่องแสดงคำตอบจริงจากเซิร์ฟเวอร์ไว้ด้านล่าง

นาฬิกาของเซิร์ฟเวอร์

GET

--:--:--

กดปุ่มเพื่อถามเวลาจากเซิร์ฟเวอร์

index.php/index/controller/ajax/time

ยังไม่ได้เรียก

ค้นหาจังหวัด

GET

ค้นหาขณะพิมพ์ โดยรอให้หยุดพิมพ์ 250 มิลลิวินาทีก่อนส่ง

    index.php/index/controller/ajax/provinces?q=...

    ยังไม่ได้เรียก

    ส่งความคิดเห็น

    POST GET

    ส่งเป็น JSON พร้อม CSRF token ลองส่งทั้งที่ว่างเพื่อดูคำตอบ 422

    ความคิดเห็นล่าสุด

    • กำลังโหลด...

    index.php/index/controller/ajax/comments

    ยังไม่ได้เรียก

    ไฟล์ในตัวอย่างนี้

    • index.phpไฟล์ทางเข้าทั้งของหน้าเว็บและของการเรียก Ajax
    • modules/index/controllers/index.phpสร้างหน้านี้ พร้อม URL ของ endpoint และ CSRF token
    • modules/index/controllers/ajax.phpเมธอด time(), provinces() และ comments() ที่ตอบกลับเป็น JSON
    • themes/default/index.htmlหน้านี้
    • themes/default/script.jsJavaScript ที่เรียก endpoint ด้วย fetch()
