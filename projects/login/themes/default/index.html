ไฟล์ในตัวอย่างนี้

  • index.phpไฟล์ทางเข้า โหลด Kotchasan แล้วเรียก Router
  • settings/config.phppassword_key และบัญชีผู้ใช้ที่เก็บเฉพาะ hash ของรหัสผ่าน
  • modules/index/controllers/index.phpรับฟอร์มเข้าสู่ระบบ/ออกจากระบบ และเลือกหน้าที่จะแสดง
  • modules/index/models/auth.phpตรวจรหัสผ่าน และเก็บผู้ใช้ที่เข้าสู่ระบบไว้ใน session
  • themes/default/login.htmlฟอร์มเข้าสู่ระบบ
